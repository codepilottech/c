HTML — Complete Starter Page

HTML creates the structure and content of a webpage. Save this as index.html and open it in a browser.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>My First Website</title>
</head>
<body>
  <header>
    <h1>Welcome to My Website</h1>
    <nav>
      <a href="#about">About</a>
      <a href="#contact">Contact</a>
    </nav>
  </header>

  <main>
    <section id="about">
      <h2>About Me</h2>
      <p>I am learning web development.</p>
      <img src="photo.jpg" alt="A profile photo" width="180">
    </section>
    <section id="contact">
      <h2>Contact</h2>
      <form>
        <label for="name">Your name</label>
        <input id="name" name="name" required>
        <button type="submit">Send</button>
      </form>
    </section>
  </main>

  <footer>&copy; 2026 My Website</footer>
</body>
</html>

CSS — Complete Starter Stylesheet

CSS controls colours, spacing, typography and responsive layout. Save as style.css and link it from your HTML head.

/* Select and style page elements */
* {
  box-sizing: border-box;
}

body {
  margin: 0;
  font-family: Arial, sans-serif;
  background: #000;
  color: #fff;
  line-height: 1.6;
}

header, footer {
  background: #0a0a0a;
  padding: 20px;
  text-align: center;
}

main {
  width: min(900px, 92%);
  margin: 30px auto;
}

button {
  background: #333;
  color: #fff;
  border: 1px solid #444;
  padding: 10px 18px;
  cursor: pointer;
}

button:hover {
  background: #666;
}

@media (max-width: 600px) {
  main { width: 95%; }
}

JavaScript — Interactive Example

JavaScript responds to user actions and updates page content. Put this script before the closing body tag or in script.js.

<button id="helloButton">Click me</button>
<p id="message">Your message appears here.</p>

<script>
  const button =
    document.getElementById("helloButton");

  const message =
    document.getElementById("message");

  button.addEventListener("click", function () {
    message.textContent =
      "Hello! You just used JavaScript.";
  });
</script>

PHP — Complete Basic Page

PHP runs on a server. Save as index.php inside XAMPP's htdocs folder, then visit http://localhost/myproject/.

<?php
$name = "CodePilot";
$year = date("Y");

function greetVisitor($visitor) {
    return "Welcome, " . htmlspecialchars($visitor);
}
?>

<html lang="en">

  <meta charset="UTF-8">
  <title>PHP Starter</title>
</head>

  <h1><?php echo $name; ?></h1>
  <p><?php echo greetVisitor("Guest"); ?></p>
  <footer>&copy; <?php echo $year; ?></footer>

</html>

Python — Complete Beginner Program

Python is used for automation, data work, web backends and general programming. Save as main.py and run python main.py.

def calculate_total(price, quantity):
    return price * quantity

def main():
    print("Welcome to CodePilot!")
    name = input("What is your name? ")
    print(f"Hello, {name}!")

    price = float(input("Enter item price: "))
    quantity = int(input("Enter quantity: "))
    total = calculate_total(price, quantity)

    print(f"Total cost: {total:.2f}")

if __name__ == "__main__":
    main()

XAMPP — Local Development Setup

XAMPP bundles Apache, MariaDB, PHP and Perl for local development. It is a tool, not a programming language.

1. Download and install XAMPP.
2. Open the XAMPP Control Panel.
3. Start Apache.
4. Start MySQL if your project uses a database.
5. Open the htdocs folder.
6. Create a folder named myproject.
7. Save your index.php inside it.
8. Visit in your browser:
   http://localhost/myproject/

Example PHP database connection:

<?php
$conn = new mysqli(
  "localhost", "root", "", "demo_db"
);
if ($conn->connect_error) {
  die("Connection failed");
}
echo "Database connected!";
?>

Node.js — Basic Web Server

Node.js runs JavaScript outside the browser. Save as server.js, then run node server.js.

const http = require("http");

const server = http.createServer((req, res) => {
  res.writeHead(200, {
    "Content-Type": "text/html"
  });

  res.end(`
    <!DOCTYPE html>
    <html>
      <body>
        <h1>Hello from Node.js!</h1>
        <p>My first local server.</p>
      </body>
    </html>
  `);
});

server.listen(3000, () => {
  console.log("Open http://localhost:3000");
});

C++ — Complete Starter Program

C++ is a compiled programming language. Save as main.cpp, compile with a C++ compiler, then run the program.

#include <iostream>
#include <string>
using namespace std;

int main() {
    string name;
    double firstNumber, secondNumber;

    cout << "Welcome to CodePilot!" << endl;
    cout << "Enter your name: ";
    getline(cin, name);

    cout << "Hello, " << name << "!" << endl;

    cout << "Enter two numbers: ";
    cin >> firstNumber >> secondNumber;

    cout << "Their sum is: "
         << firstNumber + secondNumber
         << endl;

    return 0;
}
